# Every place the app sets the pointer's cursor, a text link (the hand, unless a `.cursor` follows), or selectable
# text (the I-beam): `path | kind | count | the official line that justifies it`.
# scripts/guardrails/cursor-allow.mjs fails on a call that is not here, on a count that differs, and on a line whose
# calls are gone. Official paths are in github.com/anomalyco/opencode. "Desktop's reset" is
# packages/desktop/src/renderer/styles.css:1-45: controls and drag handles use the default cursor; the pointer
# cursor is reserved for links. A plain `<a>` is the arrow too (packages/ui/src/styles/base.css:84), and the shell
# is `select-none` outside inputs (packages/app/src/shell/shell.tsx:216), so text is the arrow unless a rule gives
# it `user-select: text`. Print the current calls with `node scripts/guardrails/cursor-allow.mjs --list`.
